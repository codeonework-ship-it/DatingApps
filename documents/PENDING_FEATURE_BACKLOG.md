## Classification and priority

- **Build/integrate:** a documented incomplete capability or integration.
- **Specify/verify:** behavior or acceptance is unresolved; inspect and test before deciding what code to change.
- **Production acceptance:** implementation exists locally or as provider adapters; deployment/device/operational evidence remains.
- **Deferred:** optional or exploratory scope without an approved delivery commitment.

**P0:** core access, safety, privacy, financial correctness, or a mandatory gate for the enabled capability. **P1:** complete an enabled release journey. **P2:** optional expansion. These are proposed delivery priorities, not the numbering of old audit documents. A feature-specific P0 can be deferred by excluding that entire optional capability from the release; core safety/privacy gates remain necessary.
